# Union files

Documents linked from Union text messages: flyers, schedules, study guides.

A file dropped here is reachable at:

    https://prasoe727.github.io/union-text/files/FILENAME

    Naming: lowercase, hyphens instead of spaces, e.g. retreat-2026.pdf
    Uploading a file with an existing name replaces it, and the link keeps working.

    This repository is PUBLIC. Anything here can be read by anyone with the link.
    Never put the member roster, phone numbers, or personal details in it.
